# ShopEase - E-Commerce Website

A frontend-only e-commerce website created using **HTML, CSS and JavaScript**.

## Features
- Responsive homepage and product grid
- Product search
- Category filtering
- Price/name sorting
- Product details
- Add to cart
- Increase/decrease quantity
- Remove items
- Dynamic cart total
- Wishlist
- Checkout and order summary
- Toast notifications
- LocalStorage for cart and wishlist persistence

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## Testing Focus
This project is also used as a self-created manual testing practice project. Test areas include product listing, search, filtering, sorting, product details, cart operations, wishlist, checkout, validation and responsive behavior.

## Project Scope
This is a frontend practice project. It does **not** use a backend, real payment gateway, or real database.
